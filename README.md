# Zbiory danych
Zbiory danych wykorzystywane w zadaniach należy pobrać z poniższych źródeł i umieścić w podfolderze `dane` obok notebooka (datasets used in the tasks should be downloaded from the sources below and placed in a `dane` subfolder next to the notebook):
- Student_Performance.csv - https://www.kaggle.com/datasets/nikhil7280/student-performance-multiple-linear-regression,
- top10K-TMDB-movies.csv - https://www.kaggle.com/datasets/ahsanaseer/top-rated-tmdb-movies-10k,
- World Top Chess Players (August 2020) - pobierany automatycznie z OpenML (downloaded automatically from OpenML), https://www.openml.org/d/43566.

Wyjątkiem jest plik [f1_race_results.csv](Tasks/dane/f1_race_results.csv), który znajduje się w repozytorium. Został zebrany przy pomocy API Ergast (obecnie rozwijanego jako [Jolpica F1](https://github.com/jolpica/jolpica-f1)) i dodatkowo przetworzony w celu inżynierii cech. Dane źródłowe udostępnione są na licencji [CC BY-NC-SA](https://creativecommons.org/licenses/by-nc-sa/4.0/), dlatego ten plik również udostępniany jest na tej licencji - tylko do celów niekomercyjnych, z podaniem źródła (the only exception is `f1_race_results.csv`, gathered with the Ergast API and processed for feature engineering; it is shared under CC BY-NC-SA, like its source data).
